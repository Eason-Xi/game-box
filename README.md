# Game Box

Turns the FoloToy AI Passport into a three-button handheld game console: it
boots into a game list, you pick a game and play, and a long press on OK takes
you back to the list at any time. Every game runs offline, with no Wi-Fi and no
phone.

![The game list and the four games](assets/images/gamebox-preview.png)

<sub>Screenshots are real code rendered on a computer with the firmware's LVGL version by `tools/render_gamebox_preview.sh`, not mock-ups.</sub>

This is a standalone repository built on the board support package and project
template from [FoloToy/ai-passport](https://github.com/FoloToy/ai-passport),
and it keeps that project's MIT license (see [LICENSE](LICENSE)).

## Games

| Game | How to play | Buttons |
| --- | --- | --- |
| Crane Stack | A box swings from a crane; release it at the right moment to build a tower. A dead-center drop is "perfect", and perfect streaks give bonus points and extra lives. The tower falls if its weight shifts too far. | OK / ▼ release, ▲ pause |
| Flappy Bird | Tap to flap through gaps between pipes. Three difficulty levels each keep a best score, with bronze, silver, gold, and platinum medals. | OK / ▲ flap, ▼ pause |
| Dodge Blocks | Blocks fly in from the right; switch lanes to dodge them as they speed up. | ▲▼ switch lanes, OK start |
| Tap Challenge | How many times can you press OK in 10 seconds? | Mash OK |

Every game saves its best score, which is shown in the game list.

## Controls

| Where | ▲ / ▼ | OK click | OK long press |
| --- | --- | --- | --- |
| Game list | Move the selection (4 per screen, scrolls when there are more) | Start the game | — |
| In game | Defined by the game | Defined by the game | Opens "return to game list?" |
| Dialog | Keep playing | Exit to the game list | — |

The battery level is shown at the top right. After 30 s without input the
backlight dims, and after 90 s it turns off; the first press after that only
wakes the screen.

## Build and flash

Requires ESP-IDF 5.5.3 (see [environment setup](docs/development/engineering/environment-setup.md)).

```bash
source <path-to-ESP-IDF-v5.5.3>/export.sh
./tools/validate.sh            # repository checks + host tests + firmware build and merged-image verification
```

The verified merged image is `build/FoloToy-AI-Passport-full.bin`; write it at
`0x0`. Note that flashing the merged image resets NVS (best scores are cleared);
to keep records, flash segments with `idf.py flash`. See
[flashing and stored data](docs/development/engineering/firmware-layout.md).

To see the UI without a device, build the firmware once (to download the LVGL
sources), then run `./tools/render_gamebox_preview.sh`; screenshots are written
to `build/gamebox_preview/`.

## Adding a game

The platform provides a common game interface, sound playback, best scores and
save data, canvas memory, shared Chinese fonts, and the host render preview. For
the porting steps, button conventions, and mapping tables for the games already
ported, see
[Game Box: platform structure and game porting guide](docs/development/engineering/game-box.md).

## Assets and licenses

- The Chinese fonts are subsets of Source Han Sans SC (SIL Open Font License
  1.1), generated by `tools/gamebox/gen_fonts.py`.
- The Flappy Bird images are drawn procedurally by
  `tools/gamebox/gen_flappy_assets.py`; no third-party art is included.
- All sound effects are synthesized in code; there are no recorded audio files.

See the [assets directory notes](assets/README.md).

## Status

The firmware build, host tests, and host render preview all pass. **On-device
acceptance has not been done yet** (frame rate, button feel, sound, and records
surviving a power cycle are still to be confirmed).
